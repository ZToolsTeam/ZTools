# Documentation

If you are contributing for the first time, read the first two guides in order to get up and running; read the next two before writing code.

- [Building from Source](building.md): Prerequisites, installing dependencies, running in dev mode, macOS packaging, open-source vs. official differences, and troubleshooting.
- [Architecture Overview](architecture.md): Main process, preload bridge, UI layer, declarative UI, native helpers, and the plugin model.
- [Coding Standards](coding-standards.md): General principles, the seven coding rules, per-layer conventions, line endings, and commit message format.
- [Testing](testing.md): Per-module test commands, test coverage requirements, and manual verification.
- [Contributing Guide](../../CONTRIBUTING.md): Reporting issues and submitting Pull Requests.

Module overviews: [`electron-client/`](../../electron-client/README.md) · [`frontend/`](../../frontend/README.md)

For plugin development, UI guidelines, manifest fields, and submission rules, see [ZTools Extensions](https://github.com/ZToolsTeam/ZTools-extensions).
