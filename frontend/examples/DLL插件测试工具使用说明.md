# DLL 插件测试工具使用说明

## 📋 概述

这是一个专门用于测试 DLL 插件的交互式网页工具，提供完整的调试功能和日志记录。

**文件位置**：`frontend/examples/dllplugin-demo.html`

## ✨ 主要功能

### 1. 动态插件选择 🎯

- ✅ 自动从系统获取已加载的 DLL 插件列表
- ✅ 点击插件卡片即可选择
- ✅ 清晰显示插件类型（C++ / Delphi）
- ✅ 高亮显示当前选中的插件
- ✅ 显示插件的完整信息（版本、作者、描述、功能列表）

**插件类型标识**：

- 🔵 **蓝色徽章** = C++ 插件（如 CPlusMathPlugin）
- 🔴 **红色徽章** = Delphi 插件（如 DelphiMathPlugin）

### 2. 详细的请求/响应日志 📜

所有 API 调用都会记录完整的日志：

**日志包含**：

- ⏰ 精确时间戳（毫秒级）
- 📤 请求信息（插件名、函数名、参数）
- 📥 响应信息（完整的 JSON 数据）
- ⚠️ 错误信息（失败原因）
- ⏱️ 性能统计（调用耗时）

**日志颜色**：

- 🟡 **黄色边框** = 请求
- 🟢 **绿色边框** = 成功响应
- 🔴 **红色边框** = 错误

**日志格式示例**：

```
[18:30:45.123]
📤 请求：调用插件函数
插件: CPlusMathPlugin
函数: Divide
参数: {
  "a": 10,
  "b": 0
}

[18:30:45.234]
❌ 错误：调用失败
插件: CPlusMathPlugin
函数: Divide
错误: 除数不能为零
```

### 3. 智能快速示例 ⚡

根据当前选择的插件，自动生成可用的测试示例：

- 加法测试：`100 + 200`
- 减法测试：`100 - 50`
- 乘法测试：`12 × 34`
- 除法测试：`100 ÷ 5`
- 幂运算：`2^10`
- 平方根：`√144`
- 阶乘：`10!`
- 斐波那契：`F(10)`
- 除零测试（错误）

只显示当前插件支持的功能。

### 4. 当前插件信息 ℹ️

页面顶部始终显示：

- 当前选择的插件名称
- 插件类型徽章
- 可用的函数列表（自动更新）

## 🚀 使用步骤

### 步骤 1：打开测试页面

在 ZTools 主程序中访问：

```
frontend/examples/dllplugin-demo.html
```

### 步骤 2：加载插件列表

- 点击 **"🔄 刷新插件列表"** 按钮
- 查看日志区域，确认请求成功
- 查看返回的插件列表

**日志示例**：

```
[18:30:45.123]
📤 请求：获取插件列表
window.dllplugin.list()

[18:30:45.234]
📥 响应：插件列表
[
  {
    "name": "CPlusMathPlugin",
    "version": "1.0.0",
    "author": "ZTools Team",
    "description": "C++ Math plugin using DLLPluginBase framework",
    "functions": ["Add", "Subtract", "Multiply", "Divide", "Power", "Sqrt", "Factorial", "Fibonacci"]
  },
  {
    "name": "DelphiMathPlugin",
    "version": "1.0.0",
    ...
  }
]
```

### 步骤 3：选择插件

- 点击任意插件卡片
- 卡片会高亮显示（绿色边框）
- 页面顶部显示当前选择的插件
- 函数下拉框自动更新
- 快速示例区域自动更新

### 步骤 4：选择函数和参数

- 从 **"函数名称"** 下拉框中选择要测试的函数
- 在 **"参数"** 输入框中输入 JSON 格式的参数
- 或点击快速示例按钮（自动填充）

**参数格式示例**：

```json
// 加法/减法/乘法/除法
{"a": 10, "b": 20}

// 幂运算
{"base": 2, "exponent": 10}

// 平方根
{"value": 144}

// 阶乘/斐波那契
{"n": 10}
```

### 步骤 5：调用插件

- 点击 **"▶️ 调用插件"** 按钮
- 查看结果显示区域
- 查看日志区域的完整记录

**成功示例**：

```
✅ 调用成功 (耗时: 2ms)
插件: CPlusMathPlugin
函数: Add
结果: {
  "result": 30
}
```

**失败示例**：

```
❌ 调用失败
插件: CPlusMathPlugin
函数: Divide
错误: 除数不能为零
```

### 步骤 6：查看日志

日志区域显示所有操作的完整历史：

- 最新的日志在最上面
- 可以滚动查看历史记录
- 点击 **"🗑️ 清空日志"** 可清除所有日志

## 📊 日志分析

### 查看原始请求

日志中会显示实际发送给 Delphi 的请求数据：

```
📤 请求：调用插件函数
插件: CPlusMathPlugin
函数: Divide
参数: {
  "a": 10,
  "b": 0
}
```

### 查看原始响应

日志中会显示 Delphi 返回的完整响应：

```
📥 响应：调用成功 (15ms)
{
  "result": 30
}
```

### 调试编码问题

如果看到乱码：

```
❌ 错误：调用失败
错误: \u53C2\u6570\u65E0\u6548
```

说明编码有问题。正常应该是：

```
❌ 错误：调用失败
错误: 参数无效
```

## 🔍 常见问题

### Q1: 看不到插件列表

**检查**：

1. 确认 DLL 文件已复制到 `Framework/Bin/DLLPlugins/` 目录
2. 重启 ZTools 主程序
3. 点击"刷新插件列表"
4. 查看日志区域的错误信息

### Q2: 调用失败："插件不存在"

**原因**：插件名称不匹配

**解决**：

1. 查看日志区域的插件列表响应
2. 确认插件名称拼写正确
3. 点击插件卡片选择（不要手动输入）

### Q3: 中文显示乱码

**原因**：C++ 插件编码问题（已在最新版本修复）

**解决**：

1. 重新编译 C++ 插件
2. 确保源文件保存为 UTF-8 编码
3. 使用 `/utf-8` 编译参数

### Q4: 日志太多，影响性能

**解决**：点击 **"🗑️ 清空日志"** 按钮清除历史记录

## 💡 高级用法

### 自定义测试

直接在 JSON 参数框中输入自定义参数：

```json
{
  "a": 999999,
  "b": 1
}
```

### 批量测试

使用浏览器控制台编写自动化测试脚本：

```javascript
// 批量测试加法
for (let i = 1; i <= 10; i++) {
  await window.dllplugin.call('CPlusMathPlugin', 'Add', {
    a: i * 10,
    b: i * 20
  })
}
```

### 性能对比

```javascript
// 测试 C++ 插件
const start1 = Date.now()
await window.dllplugin.call('CPlusMathPlugin', 'Factorial', { n: 20 })
console.log('C++ 耗时:', Date.now() - start1, 'ms')

// 测试 Delphi 插件
const start2 = Date.now()
await window.dllplugin.call('DelphiMathPlugin', 'Factorial', { n: 20 })
console.log('Delphi 耗时:', Date.now() - start2, 'ms')
```
