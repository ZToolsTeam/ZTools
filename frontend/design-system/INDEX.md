## 📊 按使用场景查找

### 新项目启动

1. 阅读 `README.md` 了解文档结构
2. 阅读 `QUICK-START.md` 快速上手
3. 参考 `DESIGN-SPECIFICATION.md` 实现组件
4. 使用 `IMPLEMENTATION-TASKS.md` 跟踪进度

### 实现特定组件

1. 在 `DESIGN-SPECIFICATION.md` 中找到对应组件章节
2. 查看组件的尺寸、样式、状态规范
3. 复制 CSS 代码示例
4. 根据需要调整

### 实现主题切换

1. 阅读 `THEME-GUIDE.md` 了解主题系统

1. 查看 `DESIGN-SPECIFICATION.md` → 响应式设计
2. 使用标准断点
