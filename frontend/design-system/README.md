## 🚀 如何使用

### 方式一：克隆到新项目

1. **复制整个文件夹**

   ```bash
   # 将 design-system 文件夹复制到新项目根目录
   cp -r design-system /path/to/new-project/
   ```

2. **根据项目调整**
   - 保持核心系统不变（间距、圆角、阴影、组件结构）
   - 可自定义品牌颜色（主色、辅助色）
   - 可调整字体家族

3. **开始实施**
   - 阅读 `QUICK-START.md` 快速上手
   - 参考 `DESIGN-SPECIFICATION.md` 实现组件
   - 使用 `IMPLEMENTATION-TASKS.md` 跟踪进度

### 方式二：作为参考文档

1. **在线查阅**
   - 将文档托管到团队知识库
   - 使用 Markdown 阅读器查看
   - 通过 Git 管理版本

2. **按需使用**
   - 需要某个组件时查阅对应章节
   - 复制 CSS 变量和样式代码
   - 参考设计原则做决策

### 方式三：创建设计系统包

1. **提取核心内容**

   ```css
   /* design-tokens.css */
   :root {
     /* 从 DESIGN-SPECIFICATION.md 复制所有 CSS 变量 */
   }
   ```

2. **创建组件库**

   ```css
   /* components.css */
   /* 从 DESIGN-SPECIFICATION.md 复制组件样式 */
   ```

3. **发布为 npm 包**（可选）
   ```bash
   npm publish @your-org/design-system
   ```

## 💡 最佳实践

### 1. 始终使用 CSS 变量

```css
/* ✅ 推荐 */
.button {
  background: var(--color-primary);
  padding: var(--spacing-md);
}

/* ❌ 不推荐 */
.button {
  background: #2d71ff;
  padding: 16px;
}
```

### 2. 遵循命名规范

```css
/* ✅ 推荐：语义化命名 */
.btn-primary {
}
.card-header {
}

/* ❌ 不推荐：无意义命名 */
.blue-button {
}
.box1 {
}
```

### 3. 移动端优先

```css
/* ✅ 推荐 */
.container {
  padding: 16px;
}
@media (min-width: 768px) {
  .container {
    padding: 32px;
  }
}
```

### 4. 保持一致性

- 同类组件使用相同的样式模式
- 统一的动画时长和缓动函数
- 一致的交互反馈
