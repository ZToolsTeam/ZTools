## 💡 常见使用场景

### 场景 1：新项目启动

```bash
# 1. 复制设计规范文件夹
cp -r design-system /path/to/new-project/

# 2. 阅读快速开始
# 打开 design-system/QUICK-START.md

# 3. 开始实施
# 参考 design-system/DESIGN-SPECIFICATION.md
```

### 场景 2：实现特定组件

```
1. 打开 DESIGN-SPECIFICATION.md
2. 搜索组件名称（如"按钮"）
3. 查看组件规范
4. 复制代码示例
5. 根据需要调整
```

### 场景 3：实现主题切换

```
1. 阅读 THEME-GUIDE.md
2. 参考 QUICK-START.md 第5步
3. 复制 CSS 变量定义
4. 实现切换逻辑
```

### 场景 4：响应式适配

```
1. 打开 DESIGN-SPECIFICATION.md
2. 查看"响应式设计"章节
3. 使用标准断点
4. 参考调整规则
```

## 🎯 核心优势

### ✨ 为什么选择这个设计系统？

✅ **完整性**

- 覆盖色彩、字体、间距、组件、布局、交互等所有方面
- 8 个核心组件的详细规范
- 从设计理念到代码实现的完整指南

✅ **双主题支持**

- 完整的亮色和暗色模式
- 所有颜色都有两个版本
- 一键切换，自动适配

✅ **可访问性**

- 符合 WCAG 2.1 AA 标准
- 色彩对比度达标
- 键盘导航支持
- 屏幕阅读器友好

✅ **响应式设计**

- 6 个标准断点
- 移动端优先策略
- 适配所有设备尺寸

✅ **开发友好**

- 使用 CSS 变量，易于维护
- 提供完整的代码示例
- 清晰的命名规范
- 模块化设计

✅ **可复用性**

- 可直接克隆到其他项目
- 保持核心系统，自定义品牌色
- 适用于多种项目类型
